Next Word Prediction using Bidirectional LSTM

This code implements a Next Word Prediction system using a Bidirectional LSTM (BiLSTM) neural network with TensorFlow/Keras. It learns patterns from a small text dataset and predicts the most likely next word for a given sequence.
